# Whisper - AI 语音转文字

使用 OpenAI 强大的 Whisper AI 技术，将您的音频文件转换为准确的文字转录。此包提供易于使用的模块，以专业级精度进行语音转文字转换。

## 🎯 您可以做什么？

**完美适用于：**
- **内容创作者**：自动转录播客节目、YouTube 视频和访谈
- **学生和研究人员**：将讲座录音和访谈转换为可搜索的文本
- **商务专业人士**：转录会议录音和电话会议
- **媒体和新闻工作者**：快速转录音频访谈和新闻发布会
- **无障碍服务**：为视频内容创建字幕和标题

## 📦 可用模块

此包包含三个强大的模块，协同工作提供完整的音频转录功能：

### 🎙️ Whisper 模型
**功能说明：** 加载并准备用于转录的 AI 模型

**主要特性：**
- 选择多种模型大小（从 Tiny 到 Large V3 Turbo）
- 硬件加速支持（CUDA/CPU）
- 针对不同精度与速度需求进行优化

**最适合：** 在处理音频文件前设置转录引擎

---

### 🎵 Whisper
**功能说明：** 将音频文件转换为带有详细时间信息的文本

**支持的音频格式：**
- MP3、MP4、WAV、WebM、FLAC
- Opus、PCM、Vorbis、AAC
- 以及更多流行格式

**主要特性：**
- 准确的语音转文字转换
- 词级时间戳（可选）
- 多语言支持
- 每个片段的置信度评分

**最适合：** 获取带有详细元数据的原始转录

---

### 📝 Whisper 片段转 SRT
**功能说明：** 将转录数据转换为标准字幕文件

**主要特性：**
- 创建行业标准的 SRT 字幕文件
- 完美的时间同步
- 可直接用于视频编辑软件
- 专业字幕格式

**最适合：** 为视频创建字幕或时间编码转录

## 🚀 工作原理

### 简单三步流程：

1. **加载模型** → 使用 Whisper 模型模块准备 AI 引擎
2. **转录音频** → 将音频文件输入 Whisper 模块
3. **创建字幕** → 将结果转换为 SRT 格式（可选）

### 典型工作流：
```
音频文件 → Whisper 模型 → Whisper → 文本 + 时间数据
                                   ↓
                            Whisper 片段转 SRT → 字幕文件
```
